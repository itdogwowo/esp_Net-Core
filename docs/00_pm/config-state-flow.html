答案：冇一個跨層 config manager 最接近嘅係開機三步鏈：nc_cfg_boot() → nc_state_boot_sync() → nc_state_apply_to_cfg()。 順序有意義：state 必須在 B05 hardware 前覆蓋回 cfg。之後所有人只讀 cfg struct。
接駁原則（新 session 照呢三條走） ① 讀值只經 nc_state_api／cfg（唔好自己 parse JSON）；加減能力只改 schema/state-keys.json＋跑生成器。 ② 緩衝只經 nc_plan（declare→commit→get）＋nc_buf；熱路徑唔准 runtime malloc／free。 ③ pixel 內容唔入 schema／plan；layout 快取刪咗只係慢一次（純快取，唔係真相）。
