份數總結：pool 2、ring N、DMA N、queue 16（索引）、snapshot 0/1。 像素 copy：effect→paint 0、paint→ring 0、ring→DMA 1（每子幀）、encode→render 0、render→硬件 0。
shared 的意思：同一個 buffer 由兩個任務「先後」使用（writer 完成 → state 轉 READY → reader 接手）， 唔係同時读写；箭嘴只會指向當前這一步的使用者。
