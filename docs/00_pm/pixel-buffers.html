Pixel 四層緩衝與 handoff

四條任務：pixel_effect_task → pixel_paint_task → pixel_encode_task → render。 按「下一步」逐格睇，或者按播放自動跑。重點：只有 ring → DMA 這一步 copy 像素。

1pixel_effect_task

算 12-bit 值流；雙 pool 交替，只傳 frame 指標（唔 copy 值）。
pool AΣnv × 2 B
seq — · 空閒
pool BΣnv × 2 B
seq — · 空閒
兩塊 pool 加起來 = 2 份值流；paint 用完 ack 才可以重用。

2pixel_paint_task

按 layout 把值流寫入環的落點；抖動／white mix 都在這裡。
直接寫環槽
0 copy · 零拷貝
呢層冇自己的像素 buffer：nc_px_ring_begin_ex() 拿到邊一格， 就即場寫入那一格。只有 0xF06B 預覽要求時，才額外 copy 一份 snapshot。

環prd ring（i80.prd）

paint 寫、encode 讀；每格 64 B 前綴（24 B 表頭＋padding）＋px×4 B（R,G,B,W）。

3pixel_encode_task

peek 最新環格 → 編碼成該硬件格式，寫入後端 DMA 槽。

這一步是唯一一次像素 copy：環（PSRAM）→ DMA 槽（internal）。
