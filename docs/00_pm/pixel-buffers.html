Pixel 四層：連續 pipeline

四層同時跑：effect 一路算、paint 一路填 ring、encode 一路搬去 DMA、render 一路送。 Buffer 逐格填滿才交棒；唔係全世界停低等一個「步驟」。 owner＝建立／擁有 lifetime；W／R＝誰寫／誰讀。
概念模擬：速率經過調整以顯示 overlap，唔係實時量測比例。
